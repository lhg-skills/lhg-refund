# 渠道升级顺序

> 核心原则：**单线推进，不要广撒网。**
> 同时投 12315、消协、12345，不是"多管齐下"，是**互相触发"不予受理"**——这是最多人踩的坑。

## 一、总顺序（照着走，每步有触发条件）

```
① 固定证据（先于一切，30 分钟做完）
        ↓
② 平台人工客服，要书面结论
        ↓  【触发：48h 无实质回复，或拿到书面拒绝】
③ 支付渠道投诉（支付宝 / 微信 / Apple）
        ↓  【触发：支付宝 72h 无果、微信 3 日无果】
④ 12315
        ↓  【触发：12315 不予受理 / 主体不明 / 已受理但拖着】
⑤ 黑猫投诉（可与之并行，建议 12315 受理后再发）
        ↓  【触发：12315 不予受理、预付卡跑路、跨部门】
⑥ 12345
        ↓  【触发：12315 终止调解，且不想打官司】
⑦ 消协（智慧315）
        ↓  【触发：终止调解 + 对方拒赔 + 证据完整】
⑧ 互联网法院 / 小额诉讼
```

**银行卡拒付（chargeback）有时限，可以提前到第③步同期做**，别等。

---

## 二、逐渠道

### ② 平台人工客服

| 项 | 内容 |
|---|---|
| 适用 | 刚开始，任何情况 |
| 入口 | App 内「我的 → 客服」转人工；要求给**工单号** |
| 目标 | **拿到书面结论**，不是拿到退款 |
| 时限 | 无强制；但微信侧对商户有考核（1 日回复 / 3 日处理） |

> 这一步的唯一 KPI：**拿到一句能被截图的话**。"已开通不支持退款"这七个字，比十次口头沟通都值钱。

### ③ 支付渠道

**支付宝**：我的 → 账单 → 该笔 → 页面底部「对此订单有疑问/投诉」。客服 95188。
商家 **72 小时**未处理，用户可申请 12315 介入。

**微信支付**：我 → 服务 → 钱包 → 账单 → 该笔 → 底部「对订单有疑惑」。
商家最晚 **1 日内**回复受理、**3 日内**处理完成；超时平台可警告/限制商户功能。

**Apple 内购**：`reportaproblem.apple.com` →「我需要」→「请求退款」。官方 **24–48 小时**给最新信息。状态查 `support.apple.com/zh-cn/118224`。

**银行卡拒付**：发卡行 App/客服，说"**交易争议/否认交易**"。时限各家不同，**越早越好**。

### ④ 12315

| 项 | 内容 |
|---|---|
| 入口 | `www.12315.cn` / `app.12315.cn` / 微信支付宝小程序 / 热线 12315 |
| 受理 | 收到投诉起 **7 个工作日**内决定受理并告知 |
| 调解 | 自受理起 **60 日**未达成协议即终止；终止后 7 个工作日内告知 |
| 性质 | **调解，不是裁决** |

现行规章是**令第 121 号（2026-04-15 施行）**，旧《暂行办法》已废止——网上攻略大多还在引旧的。

### ⑤ 黑猫投诉

`https://tousu.sina.com.cn/` →「我要投诉」→ 个人投诉 / 集体投诉。

- 无强制时限；企业首次回复即视为已处理
- **一经发布不可删除、不可撤销**——发之前想清楚
- 平台自述"不对处理结果进行干预"，它是舆论压力，不是执法

### ⑥ 12345

- 适用：12315 无管辖、主体不明、预付卡跑路、跨部门
- 明确**不受理**"须通过诉讼、仲裁、行政复议、信访等程序解决的事项"
- 各地时限不一（约 5–15 个工作日）

### ⑦ 消协（智慧315）

`https://315.cca.org.cn` 。中立第三方调解。无统一法定时限。

2026 上半年数据：受理 985,928 件、解决 567,926 件、解决率约 **57.6%**、挽回 4.47 亿元。
注意："解决"含和解与部分退款，**不等于全额退款**。

### ⑧ 互联网法院 / 小额诉讼

- 杭州 `netcourt.gov.cn`、北京、广州互联网法院：网购/网络服务合同，被告在辖区
- 全国通用：`zxfw.court.gov.cn`（人民法院在线服务）
- 小额诉讼：标的 ≤ 省级上年度就业人员年平均工资 **50%**，一审终审，**2 个月内**审结
- 立案：**7 日内**决定

> 标的几千块的退费，走小额诉讼是现实的；但时间成本按月起算，先算清楚值不值。

## 三、三条硬约束（踩了直接出局）

1. **12315 与消协/法院互斥。** 同一争议已被消协或法院受理，12315 会依《办法》第十六条第（二）项**不予受理**。别想着"多渠道同时压"。
2. **12315 禁止一事多单、禁止夹带举报。** 同一事由反复提交，会被并案或退回。
3. **黑猫发出去就撤不回。** 且平台不保证处理结果。情绪化指控（"诈骗""骗子"）还有被反诉名誉侵权的风险。

## 四、三个最常见的错误

1. **在 AI 客服里空转，不留证。**
   中消协把"AI 客服转人工难"列为 2026 上半年投诉热点第一位。用户耗掉两小时，却没拿到一句"拒绝理由"的文本——后面 12315 和支付投诉全部缺证据。
   **正确做法**：一次把订单号 + 诉求发给人工，明确要求书面答复，截图存好。

2. **同时投 12315 + 消协 + 12345。**
   直接触发"不予受理"，部门之间互相推，你的案子在系统里转一圈回到原点。
   **正确做法**：按上面的顺序单线推进，每一步的"不受理/终止"回执，才是下一步的入场券。

3. **过早说"解决了"。**
   在黑猫点"确认完成"、在工单里点"已解决"，等于主动交出筹码。钱没到账之前，**任何"完成"按钮都不要点**。

## 五、成功率这件事

除了消协那个 57.6%（还是"解决"口径，不是"全额退"），**其他渠道都没有公开成功率数据**。

任何告诉你"12315 投诉 90% 能退"的说法，都是编的。这个 skill 不编这种数。

真实规律只有一条：**证据完整的案子，在哪条渠道都更容易成；证据残缺的案子，换十条渠道也一样。**
