# 平台专属话术（可直接复制）

> `scripts.md` 是通用句式，这一份是**按平台的实际拒绝话术**写的。
> 每个平台都给两段：**首轮**（还没被拒时用）和**被拒后**（拿到拒绝原话时用）。

## 用之前先做三件事

1. 确认**收款方全称**（支付账单里看），决定找平台还是找第三方
2. 拿到**订单号 + 支付日期 + 金额**，没有这三样，任何话术都会被"请提供订单信息"挡回来
3. 想清楚**主张多少**（全额 / 未消费部分），别让对方替你算

## 三段万能结构

```
① 订单：订单号 + 日期 + 金额 + 商品名
② 事实：用了多少 / 没用什么 / 对方承诺了什么
③ 诉求：退多少 + 退到哪 + 几天内
```

## 1. 扣子 Coze

**你大概率会听到**：「已开通不支持退款」

> 注意：扣子官方文档写的是"按订单**剩余价值**退款"，和客服这句话**直接矛盾**。这是它最大的破口。

**首轮**

```
订单 {订单号}，{YYYY-MM-DD} 支付 {金额} 元，个人高阶版连续包年。
目前已使用约 {N} 个月，剩余 {M} 个月未消费。
套餐管理页载明「退款金额按订单剩余价值计算」，
请按该规则计算并退还剩余部分至原支付账户。
```

**被拒后**

```
页面写明「退款金额按订单剩余价值计算」，与您现在说的「已开通不支持退款」不一致。
请确认以哪个为准，并给出退款金额的计算方式。
```

**备注**：退款入口在「支付记录」的操作列，不叫退订叫「申请退款」。提交后立即失去全部权益，不可撤销。

## 2. 知识星球

**你大概率会听到**：「超过 72 小时不再支持退款」

> 这是**限时窗口**型，72 小时内是唯一干净的窗口。超时后平台通道关闭，只能找星主。

**首轮（72 小时内，越早越好）**

```
我于 {YYYY-MM-DD HH:mm} 加入星球《{星球名}》，支付 {金额} 元，订单号 {订单号}。
现申请退出星球并全额退款，请按原支付渠道退回。
```

**超时后（转找星主，不是找平台）**

```
{星主称呼}您好，我是 {日期} 加入的成员，支付 {金额} 元。
入群时您说明「{承诺原文}」，实际情况是「{实际}」。
我申请退出并退还 {金额} 元。请协助处理。
```

**禁忌**：别提"我已经下载了资料"——"短时间内集中下载"是官方明写的拒退理由。

## 3. 知乎盐选

**你大概率会听到**：「盐选会员服务一经开通后不可退款」

> 协议写死，硬刚条款没戏。唯一现实角度是**自动续费未显著提醒**。

**首轮**

```
订单 {订单号}，{YYYY-MM-DD} 扣款 {金额} 元，为盐选会员自动续费。
扣款前我未收到显著提醒，也未在扣费前看到取消入口。
请提供该笔扣费前的提醒记录；如无法提供，请退款并关闭自动续费。
```

**被拒后**

```
依据《消费者权益保护法实施条例》第十条第二款，自动续费应在扣费日期前以显著方式提醒。
请提供提醒记录。若无法提供，该扣费不符合规定，请退还。
```

**止损**：退不掉就立刻去支付宝/微信关掉自动扣款，并记下下次扣费日提前 3 天取消。

## 4. 得到

**你大概率会听到**：「本产品为虚拟内容服务，一经购买成功，概不退款」

> 购买须知里写死的。破口在"**是否已开始履行**"和"**是不是课程包**"。

**首轮（未开课）**

```
订单 {订单号}，{YYYY-MM-DD} 购买《{课程名}》，支付 {金额} 元。
至今未开课/未学习，课程服务尚未开始履行。
申请全额退款至原支付账户。
```

**课程包 / 训练营（引司法解释）**

```
订单 {订单号}，《{课程名}》为分{期/次}交付的课程包，已上 {X} 节，共 {Y} 节。
依据《最高人民法院关于审理预付式消费民事纠纷案件适用法律若干问题的解释》第十五条，
返还金额应为预付款扣减已兑付部分后的余额。
申请退还剩余 {Y-X} 节对应款项，计 {金额} 元。
```

**宣传不符（最有力，但要截图）**

```
购买页载明「{承诺：课时数/讲师/服务内容}」，实际为「{实际情况}」。
属于未按约定提供服务，申请退款。
```

## 5. 小鹅通

**你大概率会听到**：「请直接联系授课机构」

> 小鹅通是**工具方**，不是收款方。找错人白等一周。

**首轮（发给机构，不是小鹅通）**

```
{机构名}您好，我是《{课程名}》学员，订单 {订单号}，{YYYY-MM-DD} 支付 {金额} 元。
目前{未开课 / 已上 X 节，共 Y 节}。
申请退还 {金额} 元（{全额 / 未上课时部分}）至原支付账户。
```

**机构失联时（发给小鹅通）**

```
我是贵平台商户《{机构名}》的学员，订单 {订单号}，支付 {金额} 元。
该机构目前已{失联/停止服务}，我无法联系。
请提供该商户的实名主体信息（用于向监管部门投诉），并说明平台对该商户的资金监管方式。
```

**备注**：第二段不是要小鹅通退钱，是要**主体信息 + 施压**。机构怕平台处罚。

## 6. 剪映 / CapCut

**你大概率会听到**：「虚拟消费商品原则上不可进行转让或要求退费」

> 破口是"**取消 ≠ 退款**"——它给了显眼的"续费管理"，但不给退款入口。

**首轮**

```
订单 {订单号}，{YYYY-MM-DD} 扣款 {金额} 元，为剪映会员自动续费。
扣款前我未收到显著提醒，且当期权益未使用（未导出、未使用云空间）。
请退还该笔款项至原支付账户。
```

**被拒后（切开两件事）**

```
「续费管理」只能停止下一期扣费，不能处理已扣的这一期，这是两件不同的事。
我申请的是退还 {日期} 已扣的 {金额} 元。
依据《网络交易监督管理办法》第十八条第二款，经营者应提供显著、简便的取消或变更选项，
且不得收取不合理费用。请针对退款给出结论。
```

## 7. WPS

**你大概率会听到**：「虚拟商品已开通，不支持退款」

> WPS 有明文的「买错会员」通道，说明它内部**承认误购可退**，只是不公开标准。

**首轮（走"买错"）**

```
我于 {YYYY-MM-DD} 购买 {实际买到的套餐}，实为误购：
本意购买 {想买的套餐}，误选为 {实际套餐}。
订单 {订单号}，金额 {金额} 元，尚未使用会员权益。
请按「买错会员」通道处理退款，原路退回。
```

**通道被拒后（转"未使用"）**

```
该笔订单的会员权益我一次都没有使用，后台使用记录可核验。
服务未实际发生，请按未消费部分退款，并告知计算方式。
```

**注意**：如果用户其实是"买对了但不想用了"，**不要硬编买错**。被拆穿后连协商机会都没了，改走 `templates/auto-renewal.md`。

## 8. 百度网盘

**你大概率会听到**：「虚拟产品不能够进行退货、换货」

> 网盘的不利因素是"空间已交付"。所以别说"服务没提供"，要说"**我没使用**"。

**首轮**

```
订单 {订单号}，{YYYY-MM-DD} 支付 {金额} 元 SVIP 年费。
开通后未使用加速、未使用额外空间，未产生对应服务成本。
申请按未消费部分退款至原支付账户。
```

**重复扣款（最有力）**

```
同一订单出现两笔扣款：{日期1} {金额1}、{日期2} {金额2}，订单号 {订单号}。
属于技术原因重复扣费，请退还多扣的一笔。
```

**备注**：金额通常不大，追讨成本可能超过金额。金额小、证据弱时优先做止损（关自动续费）。

## 9. 腾讯视频 VIP

**你大概率会听到**：「本服务开通之后，不可进行转让或退订」

> 协议连"退款"两个字都不提，直接把你的诉求定义成"退订"。**必须在第一句切开。**

**首轮**

```
这不是退订请求——自动续费我已自行关闭。
我要处理的是 {YYYY-MM-DD} 这一笔 {金额} 元的扣款：
扣款前我未收到显著提醒，当期权益未使用。
请退还该笔款项至原支付账户。
```

**被拒后**

```
您回复的是"退订"，我申请的是"退款"，两者不同。
依据《消费者权益保护法实施条例》第十条第二款，自动续费应在扣费日期前显著提醒。
请提供提醒记录；如无法提供，请退款。
```

## 10. 爱奇艺

**你大概率会听到**：「VIP 会员服务系网络商品和虚拟商品，一经开通后不可转让或退款」

> 它的协议自己留了口子：「**重大瑕疵致完全无法使用**」除外。

**首轮（重大瑕疵）**

```
订单 {订单号}，{YYYY-MM-DD} 支付 {金额} 元。
开通后{会员内容全部无法播放 / 账号持续无法登录 / 付费内容全部下架}，
已尝试{重启/换设备/联系客服}，问题仍未解决。
属于协议约定的「重大瑕疵致完全无法使用」情形，申请全额退款。
```

**如果是自动续费**

```
这笔 {日期} 的 {金额} 元为自动续费，扣款前未收到显著提醒，当期未使用。
请退款并关闭自动续费。
```

**备注**：爱奇艺有人工电话 400-923-7171（9:00–24:00）。**电话比在线客服有用**，能直接找到有权限的人。

## 11. 喜马拉雅

**你大概率会听到**：「已收取的会员服务费用不予退还」

> 协议 4.16.3 写了：因平台过错无法享受权益的，予以「**补偿**」。用它的词。

**首轮（平台过错）**

```
订单 {订单号}，{YYYY-MM-DD} 支付 {金额} 元。
{付费专辑下架 / 会员专享内容无法访问 / 购买的内容无法播放}，
导致我无法享受已付费的权益，属于平台原因。
依据会员协议 4.16.3，请予补偿或退款。
```

**自动续费**

```
这笔 {日期} 的 {金额} 元为自动续费，扣款前未收到显著提醒。
请提供提醒记录；如无法提供，请退款。
```

**备注**：会员年费金额小、成功率高不了；**大师课金额大（几百到上千），才值得投入精力**。

## 12. Apple App Store

**你大概率会听到**：「不符合退款条件」

> 钱在 Apple 账上，平台无权退。**唯一入口是 reportaproblem.apple.com**。

**提交时的说明（选"未收到项目/无法使用"时）**

```
该笔购买后未能正常使用：{具体现象，如"App 打开即闪退"/"订阅内容无法加载"}。
已尝试 {重启设备 / 重新下载 / 联系开发者}，问题仍存在。
申请退还 {金额} 元至原支付方式。
```

**如果是孩子误点/账号被盗**

```
该笔购买非本人操作：{孩子使用设备时误购 / 账号在异地被登录}。
购买后未使用该内容，申请退款。
```

**金额大被拒后（走 12315）**

```
我在 App Store 购买 {项目}，订单 {MSN 开头编号}，{日期} 支付 {金额} 元。
购买后 {未提供所购服务 / 无法使用}，向 Apple 申请退款被拒。
诉求：退还 {金额} 元。
证据：Apple 收据、退款申请被拒记录、无法使用的截图。
```

**必做提醒**：退款成功后**订阅可能还在**，必须单独去 `设置 → Apple ID → 订阅` 取消，否则下期照扣。

## 通用收尾句（任何平台被拖着时用）

```
已等待 {N} 天，工单号 {X}。请在 48 小时内给出处理结论，
否则我将向 12315 提交材料。
```

## 三条不能说的话

| 别说 | 为什么 |
|---|---|
| 「你们这是诈骗」 | 定性指控，对方转法务，流程变慢；还可能被反诉 |
| 「我要曝光你们」 | 从"可以协商"变成"需要公关过目"，处理周期翻倍 |
| 「必须马上退」 | 没有时限的压力等于没有压力，改成"48 小时内" |
