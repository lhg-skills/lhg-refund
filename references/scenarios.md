# 六大场景（先认场景，再找方法）

> 平台有上千个，场景只有六类。**认对了场景，方法就定了；认错了，平台卡再全也没用。**
> 判断方法：用户说的第一句话里，通常就藏着场景。

| 场景 | 用户会怎么说 | 一句话特征 |
|---|---|---|
| S1 年费 / 长期会员 | "我买了个年费，用了几个月想退" | 一次付清，服务期长，金额大 |
| S2 自动续费 | "我忘了取消，又被扣了一年" | 按期自动扣，用户常不知情 |
| S3 课程 / 训练营 | "课还没上 / 上了两节不想上了" | 先付钱，后分期交付 |
| S4 预付卡 / 储值 | "办卡充了三千，店要关门" | 线下，充值，按次消费 |
| S5 虚拟商品 / 数字内容 | "买了模板/软件/素材，发现不能用" | 一次性交付，下载即完成 |
| S6 实体商品 | "东西不合适想退" | 有物流、有实物 |

---

## S1 年费 / 长期会员

**三个必问**

1. 什么时候买的、多少钱、服务期到哪天？
2. 用了多少？（登录记录、调用次数、播放时长）
3. 条款写的是"不可退"，还是"按剩余价值退"？

**打法（按强度排序）**

| 条件 | 主张 | 依据 |
|---|---|---|
| 付款 7 日内 | 全额退本金 | 法释〔2025〕4号 第14条 |
| 已用一部分 | 退未兑付部分 | 法释〔2025〕4号 第15条 |
| 条款写"概不退款" | 该条款可能无效 | 法释〔2025〕4号 第9条第（一）项 |
| 平台改规则/换主体/承诺不兑现 | 解除合同 | 法释〔2025〕4号 第13条 |

**模板**：`templates/formal-request.md`

**常见死法**：上来就说"我不想用了"。这句话把"权利主张"降级成"个人反悔"，对方一句"不符合退款条件"就结束。**要说"未消费部分"，不说"不想要了"。**

---

## S2 自动续费（连续包月 / 连续包年）

**这类最容易退，也最容易被自己搞砸。**

**三个必问**

1. 扣费前收到提醒了吗？（短信/站内信/弹窗，截图为准）
2. 这一期的权益用了吗？
3. 取消入口在哪？点几下能找到？

**打法：两条腿，缺一不可**

```
第一条腿：退已经扣的这一期  → 未提醒 / 未使用
第二条腿：让它别再扣下一期  → 立刻解约（不是等退款成功）
```

**只做第一条**：钱退了，下个月照扣。
**只做第二条**：下个月不扣了，这一期的钱白扔。

**依据**：实施条例第 10 条第 2 款（扣费前显著提醒）+ 网络交易办法第 18 条（显著、简便的取消入口，不得收不合理费用）。

**模板**：`templates/auto-renewal.md`

**常见死法**：跟客服说"我要退订"。对方回"已为您关闭自动续费"，事情就结束了——**退订和退款是两件事，必须在话术里切开。**

---

## S3 课程 / 训练营

**三个必问**

1. 开课了吗？上了几节？
2. 是单门课，还是课程包/训练营（多期交付）？
3. 宣传页承诺了什么？（课时数、讲师、服务、答疑）

**打法**

| 状态 | 主张 | 强度 |
|---|---|---|
| 未开课 | 服务未开始履行，全额退 | ★★★★★ |
| 课程包/训练营，刚开始 | 退未兑付部分 | ★★★★（法释〔2025〕4号） |
| 已上一部分 | 按未上课时折算 | ★★★ |
| 宣传与实际不符 | 未按约定提供服务 | ★★★★（证据要求高） |
| 已全部上完 | 基本无望 | ★ |

**模板**：`templates/course-refund.md`

**常见死法**：只找平台，不找售课方。得到、小鹅通、知识星球这类，**平台只是工具，收款方是机构/星主/老师**。找错人，白等一周。

---

## S4 预付卡 / 储值（线下）

**三个必问**

1. 卡是只能在这家用，还是到处能刷？（决定找商务局还是人民银行）
2. 还剩多少次/多少钱？有记录吗？
3. 店还在营业吗？

**打法**：见 `templates/offline-prepaid.md`。核心是**先取证再谈**——线下没有订单页，只有收据和转账记录。

**常见死法**：只在店里口头谈，谈完没留任何书面记录。对方翻脸，你手里什么都没有。

---

## S5 虚拟商品 / 数字内容

**定义**：下载即交付的东西——软件授权、模板、素材包、电子书、单次课程视频。

**三个必问**

1. 下载/激活了吗？
2. 能不能正常用？（技术故障 vs 不符合预期，是两回事）
3. 页面描述和实际差在哪？

**打法**

| 情况 | 能不能退 |
|---|---|
| 未下载、未激活 | 能，主张未交付 |
| 下载了但技术故障用不了 | 能，主张瑕疵履行 |
| 下载了，就是不喜欢 | **难**，法定排除七天无理由 |
| 描述与实际严重不符 | 能，主张欺诈/未按约定 |

**关键认知**：消保法第 25 条把"在线下载的数字化商品"**明确排除**在七天无理由之外。所以别拿"七天无理由"说事，要打"**未交付**"或"**瑕疵**"。

**模板**：`templates/digital-goods.md`

---

## S6 实体商品

这一类才是消保法第 25 条真正管的地方：**网购、7 天、无需理由、商品完好**。

四个除外：定作、鲜活易腐、在线下载/拆封的数字化商品、交付的报纸期刊。

打法最简单：平台内直接申请退货退款 → 拒收/寄回 → 留好物流单号。**不需要话术，需要的是时效**（7 天从签收起算）。

## 场景判断速查

```
用户说的第一句
├─ "年费/买了几个月" ──────────── S1
├─ "忘了取消/又扣了/自动续费" ──── S2
├─ "课/训练营/老师/机构" ───────── S3
├─ "办卡/充值/门店/健身房" ─────── S4
├─ "模板/素材/软件/下载" ───────── S5
└─ "快递/收到货/不合适" ────────── S6
```

**分不清时优先问一句**："你是想退已经扣掉的钱，还是不想再被扣？"——这一句能把 S1 和 S2 分开，而这两个的打法完全不同。
