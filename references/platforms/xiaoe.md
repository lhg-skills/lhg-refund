## 最重要的一件事：搞清楚谁收的钱

小鹅通是**工具方**（给机构搭店铺的），它不卖课。钱可能进三个地方：

1. **机构自己的微信/支付宝商户号** → 找机构，小鹅通管不了
2. **小鹅通代收** → 小鹅通有资金通道，可以要求它协助
3. **机构走的是第三方支付** → 找那个支付主体

**判断方法**：看支付账单的收款方全称。写着机构名的，就别浪费时间找小鹅通客服。

## 打法：双线并进

```
第一条线：售课机构 → 要退款 → 拒绝就固定证据
第二条线：小鹅通 → 举报该机构违规经营（不是要它退钱）
```

第二条线的作用不是退钱，是**施压**：小鹅通对机构有管理权，机构怕被平台处罚。这一招在"机构跑路/失联"时特别有用。

## 破口

- 机构跑路 → 找小鹅通要"机构主体信息"（用于投诉/起诉），同时向 12315 举报机构
- 课程未开课 → 主张"服务未开始"，要求全额
- 训练营/多期课 → 法释〔2025〕4号，主张退未兑付部分

> 这类平台最容易出现"两边踢皮球"。**破局点只有一个：拿到收款主体全称。** 拿到了才有得谈。
