# 话术库（短句层）

> 这里放"一句话怎么说"。整篇可提交的正式文本在 `templates/`。
> 所有句式都遵守四段结构：**订单 → 事实 → 依据 → 诉求**。

## 五条原则

1. **先给可核对的信息**（订单号、日期、金额），再提要求。客服没法用"请提供订单信息"拖你。
2. **一句话不超过 40 字**。长了对方只读前半句。
3. **不用形容词**。"太过分""霸王条款""诈骗"一律删掉，换成可验证的陈述。
4. **每轮只提一个诉求**。又要退款又要道歉又要赔偿，对方只会回你一句"已记录"。
5. **不主动说"我要投诉"**。先说"如无法解决，我会向 12315 提交材料"——是告知路径，不是威胁。

---

## 场景 1：首轮找在线客服

**破机器人**（连发两次，间隔 10 秒）：

```
转人工
```

**首句**——不要问"能不能退"，那等于送对方一个"不能"：

```
订单 {订单号}，{YYYY-MM-DD} 支付 {金额}，开通后未实际使用，申请退款，请原路退回原支付账户。
```

> 为什么有效：三样可核对的东西一次给全，对方没有拖时间的借口。

---

## 场景 2：对方说"已开通不支持退款"

按你手里的牌选一张，**不要四张一起打**：

**A. 条款自相矛盾**

```
购买页写的是「{页面原文}」，与现在的说法不一致。请确认以哪个为准，并把依据发我。
```

**B. 付款前没有显著提示**

```
这个限制在付款前没有显著提示，藏在折叠协议里。按《民法典》第四百九十六条，格式条款未履行提示说明义务的，我可以主张其不成为合同内容。
```

**C. 服务没实际使用**

```
服务未实际使用，未产生对应成本。请按未消费部分退款，并告知计算方式。
```

**D. 是自动续费扣的**

```
这笔是自动续费扣款，扣款前未收到显著提醒。请提供扣款前的提醒记录。
```

## 场景 3：对方要"退到平台余额"

```
我不接受退到平台余额，请原路退回原支付账户。
```

对方坚持时：

```
这不是退款，是把已支付的钱换成只能在贵平台使用的代金券。如只能这样处理，请出具书面说明，我据此向 12315 反映。
```

> 这条必须咬住。退余额 = 钱没回来，只是换了个地方锁着。

---

## 场景 4：转人工 / 要工单号

```
请转人工客服，这个问题机器人处理不了。
```

一直不给转：

```
请给我工单号，我按工单跟进。
```

---

## 场景 5：拖延

```
已等待 {N} 天，工单号 {X}。请在 48 小时内给出处理结论，否则我将向 12315 提交材料。
```

> 时限要具体。"尽快"等于没有时限。

---

## 场景 6：对方要你"证明没用过"

反过来让对方举证——使用记录在它系统里：

```
使用记录在贵平台系统内，请调取并告知具体使用时间与时长。
```

---

## 场景 7：只肯退一部分，但不给算法

```
请给出退款金额的计算方式：扣除了哪些费用、依据哪一条。
```

> 拿不到计算依据，说明这个数字是随口报的。继续要，别接受"系统自动计算的"。

---

## 场景 8：踢皮球（"钱在苹果 / 在服务商 / 在代理商"）

```
请书面告知收款主体全称，以及该订单在对方系统的编号，我据此向收款方申请。
```

> 拿到"主体全称 + 对方订单号"这两样，你才可能真的推动。只要一句"你去找苹果"，就是没给。

## 禁忌词替换表

| 别说 | 改成 |
|---|---|
| 你们这是诈骗 | 这笔扣款与页面描述不一致 |
| 霸王条款 | 该条款未在付款前显著提示 |
| 我要曝光你们 | 我会按流程向监管部门反映 |
| 必须马上退 | 请在 48 小时内给出结论 |
| 我不差这点钱 | （删掉，这句只会让对方觉得你不急） |
| 我都用了这么久了 | 我实际使用了 {X}，剩余部分未消费 |

---

## 万能骨架（任何平台都能套）

```
订单 {号}，{日期} 支付 {金额}，{未使用 / 使用约 X%}。
依据 {条款第 X 条 / 购买页承诺 / 法规第 X 条}，申请退款 {金额} 至原支付账户，
请于 {N} 个工作日内处理。
如无法解决，我将向 12315 提交材料。
```

四行，信息齐全，不卑不亢。写不出来的时候就用这个。
