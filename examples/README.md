# 完整案例（照着这个格式输出）

> 两个真实高频场景，演示 `SKILL.md` 的「输出契约」怎么落地。
> 看这两份，比读十页框架更快。

---

## 案例一：年费会员用了三个月，客服说"已开通不支持退款"

**用户原话**：*"我七月份买了个年费会员，869，用了两三个月吧，现在不想用了，客服说已开通不支持退款，这能退吗？"*

### 输出

```
## 你的情况
- 收款方：待确认（请翻支付宝/微信账单看收款方全称）
- 付费形态：年费会员（一次付清，服务期一年）
- 消耗程度：约 3 个月 / 12 个月
- 对方说法：「已开通不支持退款」

## 判断
- 路径：B 按比例退（退未兑付的 9 个月）
- 理由：年费是"先付钱、后持续兑付"的服务，未使用的部分没有履行。
  「已开通不支持退款」属于排除消费者请求返还预付款权利的格式条款，
  依《法释〔2025〕4号》第九条第（一）项可能无效。

## 现在做什么（按顺序）
1. 翻支付账单，确认收款方全称 → 决定找平台还是找第三方
2. 截订单页（订单号、金额、购买日期）
3. 查实际使用记录（登录/调用/播放时长）→ 一句话说清"用了多少"
4. 把下面这段话发给在线客服，要求转人工、给工单号
5. 48 小时无实质回复 → 支付宝/微信交易投诉
6. 仍无果 → 12315（投诉对象是收款主体全称）

## 可以直接发的话
> 订单 {订单号}，2026-07-XX 支付 869 元，年费会员，有效期至 2027-07-XX。
> 目前已使用约 3 个月，剩余 9 个月未消费。
> 依据《最高人民法院关于审理预付式消费民事纠纷案件适用法律若干问题的解释》
> 第十五条，返还金额应为预付款扣减已兑付部分后的余额。
> 申请退还剩余 9 个月对应款项，原路退回原支付账户。
> 请于 7 个工作日内答复。

## 如果被拒
- 第一步：要求对方书面说明拒绝依据（哪一条条款、付款前是否显著提示过）
- 第二步：48 小时内没有书面结论 → 支付宝「对此订单有疑问」
- 第三步：12315，投诉对象填收款方企业全称

## 证据清单
- [ ] 订单页（订单号、金额、日期）
- [ ] 支付账单（收款方全称）
- [ ] 会员有效期截图
- [ ] 客服拒绝原话截图
- [ ] 使用记录（证明只用了 3 个月）
```

**这个案子的关键动作**：把"我不想用了"换成"剩余 9 个月未消费"。前者是反悔，后者是权利。

## 案例二：连续包月忘了取消，被扣了一年

**用户原话**：*"我开了个连续包月，忘了取消，昨天直接扣了我一年的钱，能退吗？"*

### 输出

```
## 你的情况
- 收款方：待确认
- 付费形态：连续包月 → 本次按年扣费（属于自动续费）
- 消耗程度：刚扣，当期未使用
- 对方说法：尚未沟通

## 判断
- 路径：A 全额退当期 + 立即解约（两条腿，缺一不可）
- 理由：扣费前未收到显著提醒，违反《消费者权益保护法实施条例》
  第十条第二款；当期权益未使用。

## 现在做什么（按顺序）
1. 【先做】解约：平台内「续费管理」+ 支付宝「免密支付/自动扣款」+ 微信「自动续费」
   四处都检查一遍（平台内关了，支付宝里可能还挂着）
2. 截图扣费账单 + 检查有没有收到过提醒（短信/站内信/弹窗）
3. 发下面的话给客服，明确"这是退款，不是退订"
4. 48 小时无回复 → 支付渠道投诉
5. 3 日无果 → 12315

## 可以直接发的话
> 这不是退订请求——自动续费我已经自行关闭。
> 我要处理的是 {日期} 这一笔 {金额} 元的扣款：
> 扣款前我没有收到显著提醒，且当期权益未使用。
> 请退还该笔款项至原支付账户。

## 如果对方回"已为您关闭自动续费"
> 感谢关闭。我申请的是退还 {日期} 已扣的 {金额} 元，不是关闭续费。
> 请针对退款给出结论。

## 证据清单
- [ ] 扣费账单截图（时间、金额、收款方）
- [ ] 提醒记录（有就截，没有就在话术里写明"未收到"）
- [ ] 解约成功的截图（证明已停止未来扣费）
```

**这个案子的关键动作**：**先解约，再要钱。** 顺序反了，会在等退款的过程中被再扣一次。

---

## 两个案例的共同点

1. 第一句给的是**可核对的信息**（订单号、日期、金额），不是情绪。
2. 主张的是**具体金额**，不是"给个说法"。
3. 都留了**下一步渠道**和触发条件，不是"你去投诉吧"。
4. 都没有承诺结果。

## 反面示例（别这样写）

```
❌ "他们这是霸王条款，明显违法，你直接去12315告他们"
   → 定性过早，用户拿不到退款还会觉得被忽悠

❌ "你先跟客服好好说说，态度好一点应该能退"
   → 没有信息，没有依据，纯粹安慰

❌ "这种平台都是骗子，建议曝光"
   → 情绪输出，可能涉及不实指控，对用户没有任何帮助
```
