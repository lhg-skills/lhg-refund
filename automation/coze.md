# 扣子 Coze（全自动）

> 唯一走过完整实测的路径：2026-10-12，个人高阶版连续包年，申请 ¥869.00，实到 ¥867.10。
> 本版把执行层从 agent-browser 换成 ego-lite，**点击路径不变，操作方式变了**。

## 前置条件

- [ ] 用户本人在场（登录和最终确认要他做）
- [ ] ego-lite 可用：`ego-browser --version` 能打印版本
- [ ] 账号确实有付费订单（免费账号会在第 3 步如实终止）

## 执行步骤

### 0. 开空间，从首页进

```js
const task = await taskSpace("coze refund");
const page = task.page("p1");
await page.goto("https://www.coze.cn/");
console.log({ spaceId: task.spaceId, page: page.label });
console.log(await page.snapshot());
```

> ❌ 不要 `goto("https://www.coze.cn/subscription/manage")`。直达四层页面是脚本特征，也违反 `human-ops.md`。

### 1. 判断登录态

看 snapshot 右上角：有头像/昵称 → 已登录，跳到第 3 步；显示"登录" → 第 2 步。

### 2. 登录（交还用户）

```js
// 点开登录弹窗后，先把二维码/验证码页留在屏幕上，然后交出控制权
await task.handOff();
```

告诉用户：

> 浏览器窗口已经打开登录页，请用抖音 App 扫码（或手机号+验证码）完成登录，好了跟我说一声。

用户确认后：

```js
const spaceId = 12; // 换成上一轮打印的 spaceId
const task = await takeOverTaskSpace(spaceId);
const page = task.userPage();
console.log(await page.snapshot());
```

**注意**：agent 不输密码、不读短信、不猜手机号。登录失败最多 3 次，失败即停。

### 3. 进订阅管理（点进去，不直达）

右上角头像 → 会员中心 / 订阅管理。逐级点击，每步之间停 300–900ms。

记录四项，后面要汇报：

- 套餐名称与状态（生效中 / 订购中）
- 到期日
- 自动续费状态（已关闭 / 已开启）
- 剩余积分（含即将过期的数量）

### 4. 决策树（停，等用户拍板）

```
自动续费已关闭？
├─ 是 → 到期不再扣费：
│   ├─ A 什么都不做：权益保留到到期日，零风险
│   └─ B 申请退款：拿回剩余价值，但立即失去全部权益、不可撤销
└─ 否 → 先关自动续费，再按 A/B 选
```

**把 A/B 的利弊讲清楚，等用户明确表态。** 不说"确认退款"，不进第 5 步。

### 5. 定位退款入口

```
套餐管理页 → 顶部页签「套餐订阅」
→ 下滑到「支付记录」表格 → 目标订单行
→ 最右侧「操作」列 → 「申请退款」
```

找不到时先 `snapshot({ scope: "full_page" })`——表格通常在折叠线以下。

### 6. 核对弹窗（只看不点）

五项逐条记录：退款商品 / 订单编号 / 支付方式 / 预计退款金额 / 条款原文。

条款实测原文（以实时为准）：

> 退款金额按订单剩余价值计算。提交后将收回对应剩余权益，申请提交后不可撤销。

**停在这里**，复述给用户：

> 订单 {号}，预计退 ¥{X}，原路退回支付宝。点下去会员立即失效，且不可撤销。确认吗？

### 7. 提交（用户确认后）

点「确认退款」→ 等成功提示 → 点「完成」。

记录成功提示原文，实测为：

> 退款申请已提交，预计 2-3 个工作日原路到账，请注意查收。申请退款金额 ¥869.00

报错就原样记录并停止，不重试。

### 8. 四项核验

```js
// 回到支付记录，确认状态变了
console.log(await page.snapshot({ scope: "full_page" }));
```

1. 成功提示是否出现、有无报错
2. 支付记录操作列是否变成「退款处理中」
3. 会员页是否仍显示原套餐（退款处理期间不刷新，属正常）
4. 实际金额与去向（实测有尾差：869.00 → 867.10，差 1.90，**必须如实标注**）

### 9. 收尾

```js
await task.finish({ keep: [] });
```

## 常见失败

| 现象 | 处理 |
|---|---|
| 找不到「申请退款」按钮 | 先 full_page 快照；仍没有 → 页面改版，记录并走人工路径 |
| 弹窗金额与预期差很多 | 停，把两个数字都给用户，让他决定 |
| 提交后报错 | 原样记录，不重试；转 12315 前先联系客服要工单 |
| 出现人机验证 | 停，转人工；不要尝试过验证 |

## 不做的事

- 不创建/删除 Bot、项目、资源
- 不猜没写在本文件里的 URL
