# 正式退款申请（邮件 / 工单）

> 用在：在线客服踢皮球、要求"发邮件申请"、或你要留一份书面记录的时候。
> 特点：**书面化、可归档、能当证据**。客服聊天记录容易被清，邮件不会。

## 标题（决定会不会被当垃圾邮件）

```
退款申请｜订单 {订单号}｜{YYYY-MM-DD} 支付 ¥{金额}
```

不要写"投诉""举报""骗子"——标题带这些词，很多系统会直接转投诉流程，处理周期翻倍。

## 正文模板

```
主题：退款申请｜订单 {订单号}｜{YYYY-MM-DD} 支付 ¥{金额}

您好：

我是 {姓名}，账号 {手机号/邮箱}。

一、交易信息
- 订单编号：{订单号}
- 商品/服务：{套餐全称}
- 支付时间：{YYYY-MM-DD HH:mm}
- 支付金额：¥{金额}
- 支付方式：{支付宝/微信/银行卡尾号}
- 收款方：{账单上的收款方全称}

二、事实
{购买后是否使用、使用到什么程度、是否开课、是否有登录/播放/调用记录}

三、依据
{三选一或组合：
 a) 平台条款第 {X} 条：「{原文}」
 b) 购买页/宣传页承诺：「{原文}」（截图见附件）
 c) 法规：《{法规名}》第 {X} 条——{一句话说明}}

四、诉求
请于 {N} 个工作日内，将 ¥{金额} 原路退回至原支付账户。
我不接受退至平台余额、代金券或其他非现金形式。

五、附件
1. 订单详情截图
2. 支付账单截图（含收款方）
3. {条款页/宣传页截图}
4. {使用记录截图，如有}

如需补充材料，请通过本邮箱联系我。

{姓名}
{YYYY-MM-DD}
```

## 三条写作纪律

1. **只写能证明的**。"我完全没用过"要能对上记录；不确定就写"使用时长不足 X 分钟"。
2. **金额写死**。不要写"退还剩余部分"，要给数字；给不出就写"按未消费天数折算，请贵司出具计算方式"。
3. **不写情绪句**。整封信里不出现"太过分""欺骗""曝光"。一出现，这封信就从"可以处理的申请"变成"需要公关/法务过目的投诉"。

## 如果对方回"不支持退款"

不要重复发同一封。换角度，只回一段：

```
关于「不支持退款」的回复，我需要确认两点：

1. 该限制在付款前是否以显著方式提示？请提供提示的位置与截图。
2. 若服务尚未实际使用，贵司依据哪一条拒绝退还对应款项？

请书面回复上述两点。如无法提供，我将按流程向 12315 提交材料。
```

## 跟进节奏

| 时间 | 动作 |
|---|---|
| 发出后 24h | 无回复 → 同一邮件回复"请确认是否收到" |
| 48h | 仍无实质回复 → 转 `templates/complaint-12315.md` |
| 7 天 | 有回复但拒绝 → 看拒绝理由是否回应了你的"依据"，没回应就再追一轮 |
| 15 天 | 仍僵持 → 支付渠道争议（`templates/payment-channel.md`） |

**每一封都留着。** 后面 12315 要的"已与商家协商未果"的证明，就是这些邮件。
