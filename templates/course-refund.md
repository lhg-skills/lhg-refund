# 课程 / 训练营退款

> 适用于：得到、小鹅通、知识星球、各类训练营、1v1 咨询、陪跑服务。
> 共同点：**平台只是工具，收款方是机构/老师/星主**。找错人，白等一周。

## 第一步：找对人

看支付账单的**收款方全称**：

| 收款方显示 | 找谁 |
|---|---|
| 机构/公司名 | 找机构，平台管不了 |
| 平台名（如小鹅通） | 平台代收，平台有处置权 |
| 个人（老师微信/支付宝） | 找老师本人，同时留好转账记录 |
| Apple | 走 `reportaproblem.apple.com` |

**拿不到收款方名称 = 没法开始。** 先让用户去翻账单。

## 第二步：定性（决定能退多少）

| 状态 | 主张 | 依据 |
|---|---|---|
| 未开课 / 未开营 | 服务未开始履行，全额退 | 未履行 |
| 课程包 / 多期训练营，刚开始 | 退未兑付部分 | 法释〔2025〕4号 第15条 |
| 已上部分 | 按未上课时折算 | 同上 |
| 宣传与实际不符 | 未按约定提供服务 | 宣传页截图 |
| 已全部上完 | 基本无望 | — |

**关键区分**：单门课（一次性交付）看"是否履行"；课程包/训练营（分次交付）才能用预付式消费那套。

## 第三步：申请模板

发给**机构/老师**（不是平台客服）：

```
{老师/机构名}您好：

我是 {姓名}，于 {YYYY-MM-DD} 购买《{课程名}》，
订单号 {订单号}，支付 {金额} 元。

目前进度：{未开课 / 已上 X 节，共 Y 节}。

申请退还 {金额} 元（{全额 / 未上课时折算部分}），原路退回原支付账户。

说明：该课程为分次交付的服务，未交付部分我未接受服务。
依据《最高人民法院关于审理预付式消费民事纠纷案件适用法律若干问题的解释》
第十五条，返还金额应为预付款扣减已兑付部分后的余额。

请于 7 日内答复。
```

**为什么引这一条**：机构最常用的挡箭牌是"虚拟内容一经售出不退"。这一条正好把"分次交付"和"一次性交付"区分开——你的课还没上完，它就不是"已交付"。

## 第四步：被拒之后

平台方（小鹅通/知识星球）不是收款人时，**不要投诉平台**，投诉对象是收款机构。

12315 里填的是**机构的企业全称**，不是平台名。填错会被退回。

如果机构失联：
- 找平台要"该机构的实名主体信息"（用于起诉/投诉）
- 向平台举报该机构违规经营（平台对机构有管理权，这是唯一能施压的点）

## 证据清单

- [ ] 课程页截图（含宣传承诺：课时数、讲师、服务内容）
- [ ] 订单页（订单号、金额、时间）
- [ ] 支付账单（收款方全称）
- [ ] 上课记录 / 学习进度截图
- [ ] 与老师/机构的沟通记录

## 常见死法

1. **只说"不想学了"** → 对方回"课程已开通"。要说"未上课时的部分未接受服务"。
2. **找平台客服要钱** → 平台说"请找机构"，来回踢。要先确认收款方。
3. **没有宣传页截图** → "宣传不符"这条最有力，但没截图就变成"你觉得不符"。
