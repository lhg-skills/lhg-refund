# 自动续费：取消 + 退当期

> 这是所有场景里**最容易办成、也最容易被自己搞砸**的一类。
> 搞砸的方式只有一种：只做了"取消"，没做"退款"——或者反过来。

## 两条腿，必须同时走

```
腿一：退已经扣掉的这一期
      理由 = 扣费前没显著提醒 / 这一期没使用

腿二：让它别再扣下一期
      动作 = 立刻解约（在平台、支付宝、微信、Apple 四处都检查一遍）
```

**只做腿一**：钱退了，明年照扣，你还得再来一次。
**只做腿二**：明年不扣了，今年这笔白扔。

---

## 腿二：解约（先做这个，5 分钟）

自动续费可能挂在**四个地方**，平台内关了不代表支付宝里关了：

| 位置 | 路径 | 说明 |
|---|---|---|
| 平台内 | App → 我的 → 续费管理 / 订阅管理 | 只关平台侧 |
| **支付宝** | 我的 → 设置 → 支付设置 → 免密支付/自动扣款 → 找到该项目 → 关闭 | **最容易漏，也最关键** |
| **微信** | 我 → 服务 → 钱包 → 支付设置 → 自动续费 → 关闭 | 同上 |
| **Apple** | 设置 → Apple ID → 订阅 → 选中 → 取消订阅 | iOS 内购只在这里能关 |

> 以当前 App 版本为准，路径会改。找不到就在设置里搜"自动续费""免密支付""订阅"。

**为什么四边都要查**：用户在平台里点了取消，但扣款协议是当初在支付宝签的——平台取消了，支付宝照样扣。这是最高频的"我明明取消了还被扣"。

---

## 腿一：退当期（话术）

**第一句就切开"退订"和"退款"：**

```
这不是退订请求——自动续费我已经自己关闭了。
我要处理的是 {YYYY-MM-DD} 这一笔 {金额} 元的扣款：
扣款前我没有收到显著提醒，且当期权益未使用。
请退还该笔款项至原支付账户。
```

**如果对方回"已为您关闭自动续费"**（答非所问），追一句：

```
感谢关闭。我申请的是退还 {日期} 已扣的 {金额} 元，不是关闭续费。
请针对退款给出结论。
```

**如果对方说"已扣费不支持退"**：

```
依据《消费者权益保护法实施条例》第十条第二款，自动续费应在扣费日期前以显著方式提醒。
请提供该笔扣费前的提醒记录；如无法提供，请退款。
```

---

## 三个必须问清的问题

1. **扣费前收到提醒了吗？**
   短信、站内信、App 弹窗、邮件——任何一种都算。**没有 = 你最强的牌。**
2. **这一期用了吗？**
   用了一次也是用了，别说"完全没用"。如实说"仅使用 X 次"，可信度反而高。
3. **扣款是从哪走的？**
   支付宝/微信/Apple/银行卡。决定你找谁——**平台客服管不了支付宝里的协议**。

---

## 时间线

| 时间 | 动作 |
|---|---|
| 发现被扣当天 | 先解约（腿二），再取证（账单截图、提醒记录） |
| 当天 | 提退款（腿一） |
| 48h 无回复 | 支付宝/微信交易投诉 |
| 3 日无果 | 12315 |
| 退款到账 | 核对金额，确认没有"退到平台余额" |

---

## 三个坑

1. **以为"取消"= "退款"**。取消只是停止未来扣费，已扣的钱一分不退。
2. **以为"退款成功"= "订阅已取消"**。Apple 尤其如此：退款到账，订阅还在，下期照扣。
3. **接受"退到平台余额"**。那不是退款，是把钱换成只能在这家花的代金券。

---

## 一句话总结

> **先解约，再要钱。** 顺序反了，你会在等退款的过程中被再扣一次。
