# 虚拟商品 / 数字内容退款

> 软件授权、模板、素材包、电子书、单次课程视频、AI 额度包。
> 特征：**下载即交付**。这一类被法律明确排除在"七天无理由"之外。

## 先纠正一个最常见的错误认知

很多人上来就说"我要七天无理由退货"。

**没用。** 消保法第 25 条把"在线下载或者消费者拆封的音像制品、计算机软件等数字化商品"**明确列为除外**。对方一句"这是数字化商品，不适用无理由退货"，你就没话了。

能用的只有三条：

| 角度 | 适用 | 强度 |
|---|---|---|
| **未交付** | 没下载、没激活、没收到 | ★★★★★ |
| **瑕疵履行** | 下载了但用不了（文件损坏、密钥无效、功能缺失） | ★★★★ |
| **描述不符** | 宣传的功能/内容与实际严重不一致 | ★★★ |

"我就是不喜欢" → 不在这三条里，别硬套。

## 三个必问

1. **下载/激活了吗？** 没激活 = 未交付，最好打。
2. **是不能用，还是不好用？** "不能用"是瑕疵，"不好用"是偏好。这两个在客服那里是完全不同的结论。
3. **页面怎么写的？** 功能列表、适用版本、是否含更新——截图。

## 申请模板

```
订单号 {X}，{YYYY-MM-DD} 支付 {金额} 元，商品为《{商品名}》。

问题：{三选一}
A. 该商品我尚未下载/激活，服务未实际交付，申请全额退款。
B. 下载后无法正常使用：{具体现象，如"密钥提示已失效"/"文件损坏无法打开"}，
   已尝试 {X}，仍无法使用。属于交付物存在瑕疵，申请退款。
C. 商品页面载明 {宣传内容}，实际 {实际情况}，与描述不符，申请退款。

请原路退回至原支付账户。
```

## 特殊情况：额度包 / 积分包

AI 类产品常卖"次数包""积分包"。这类要注意：

- **未使用** → 主张未消费，按剩余额度退
- **部分使用** → 按剩余比例退（扣子就是这种，官方写明按剩余价值）
- **已用完** → 没得退

**先问清"用了多少额度"**，再谈。用完了还要求全退，只会让对方觉得你不讲理，后面真有问题也不认真对待。

## 平台政策差异

| 平台 | 官方口径 |
|---|---|
| 扣子（积分包） | 按剩余价值退，是同类里最松的 |
| WPS | 有"买错会员"通道，误购可申请 |
| 剪映 / 网盘 / 视频会员 | 一经开通不可退，只能打"自动续费未提醒"或"重大瑕疵" |

## 一个反向技巧

如果确实是"买错了"（买错档位、买错账号、重复购买），**别说是"不想要了"，直接说"误购"**。

误购是客观错误，反悔是主观意愿。同样的事实，前者过审率高得多——WPS 甚至专门开了"买错会员"通道。
