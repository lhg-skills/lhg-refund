# 线下预付卡 / 门店类退款

> 健身房、美容院、教培、洗车、餐饮储值、摄影套餐。
> 特点：**没有"订单页"，只有一张收据 + 一个微信转账记录**。所以取证方式完全不同。

## 第一步：先分清是哪一种

| 类型 | 特征 | 主管 |
|---|---|---|
| **单用途预付卡** | 只能在发卡企业用（健身卡、美容卡、储值卡） | 商务部门（备案/资金存管） |
| **教育培训** | 课程、课时包 | 教育部门 / 市场监管 |
| **多用途预付卡** | 可在多家商户用（如某些商超卡） | 人民银行（备付金） |
| **会员费/年费** | 不储值，买的是"资格" | 市场监管 |

**分不清就问一句**："这张卡是只能在这家店用，还是到处都能刷？"——答案决定找谁。

## 第二步：取证（线下最容易输在这一步）

没有 App 就没有订单页，所以要手动攒：

- [ ] 付款凭证：微信/支付宝转账记录（**含收款方名称**）、POS 小票、收据
- [ ] 合同/协议：纸质合同拍照，**重点拍背面小字和签字页**
- [ ] 卡面/卡号/余额截图（会员系统里的余额页）
- [ ] 消费记录：每次去了刷几次、剩多少次
- [ ] 对方承诺：销售说的"随时可退""不满意全额退"——微信聊天记录就是证据
- [ ] 门店状态：如果已停业，拍门头照片 + 物业/商场证明

> 线下退款最常见的死法：**只有一张转账截图，没有合同、没有余额记录**。对方一句"你这是赠送给朋友的"就把你堵死。

## 第三步：谈（先礼后兵，但要留痕）

**不要只在店里口头谈。** 口头谈完对方不认，你没有任何记录。

谈完当场发一条微信（或短信）确认：

```
今天在店里沟通的事，我确认一下：
我于 {日期} 购买 {项目}，金额 {X}，剩余 {N} 次未消费。
我提出退还剩余部分 {金额}，店方答复：{原话}。
如有出入请今天内回复，否则我按此记录处理。
```

对方不回 = 默认；对方反驳 = 你拿到了它的书面说法。**两种结果都比"谈过了"强。**

## 第四步：升级顺序

```
门店协商 → 品牌总部/加盟商 → 12315 → 商务局（单用途预付卡）
→ 消协 → 法院小额诉讼
```

**如果是连锁/加盟**：直接找总部。加盟店跑路，总部往往有连带责任压力，比跟店长耗有效得多。

**如果已停业/跑路**：

1. 立刻联合其他会员（建群，人数就是筹码）
2. 向**商务部门**举报未备案/未存管（这是它们最怕的，涉及行政处罚）
3. 向市场监管部门举报
4. 金额大的走集体诉讼

## 第五步：拒绝这三种"解决方案"

| 对方提的方案 | 为什么不能接 |
|---|---|
| **转卡给他人** | 转不出去等于没退；转出去也常被收高额手续费 |
| **延期/换项目** | 你不想继续消费了，延期只是把问题往后推 |
| **退到店内余额** | 钱没出来，还在它账上，店一关就归零 |

除非你**确实还愿意在这家消费**，否则一律要求原路退回。

## 一句话模板（发给店长/总部）

```
我是 {姓名}，{日期} 在 {门店} 购买 {项目}，支付 {金额}，目前剩余 {N} 次未消费。
因 {个人原因/门店服务与承诺不符}，申请退还未消费部分 {金额}，原路退回原支付账户。
请在 7 日内答复。逾期我将向 12315 及商务部门反映。
```

## 说句实话

线下预付卡是**所有退费场景里最难的一类**：没有平台兜底、没有在线入口、商家现金流紧。

所以策略要变：**不要追求"全额退"，追求"尽快拿回大部分"**。能谈到 70% 现金当场结清，比打半年官司拿 100% 更划算。
