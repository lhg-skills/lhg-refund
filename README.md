# 全平台退费助手 · lhg-refund

> 不管你在哪个平台、买的年费还是自动续费、是一次性课程还是预付卡——先判断，再动手，别一上来就求人。

## 它解决什么

绝大多数退款失败，不是"平台不给退"，而是四件事里有一件弄错了：

1. **找错人**——iOS 内购去找平台客服（钱在苹果账上，平台根本无权退）
2. **没证据**——嘴上说"我没用"，系统里查得到使用记录
3. **只打一个渠道**——在线客服拒绝就放弃了
4. **话说太满**——开口"你们诈骗"，对方直接转法务

这个 skill 把四件事拆成可执行的步骤：先判四要素，再选四条路径，然后按渠道顺序升级，每一步都给你能直接复制的话。

## 怎么装

```bash
npx skills add lhg-skills/lhg-refund
```

装不上就直接克隆本仓库到你的技能目录。抖音/WorkBuddy/扣子编程/Trae 用各自的技能导入功能上传 zip。

**怎么算装好了**：Agent 能在已安装的 skill 里看到 `lhg-refund`，并报出版本号（与 `manifest.yaml` 的 `version` 一致）。

## 怎么用

直接说人话：

> "我在 XX 平台买了个年费会员，用了两个月想退，客服说已开通不支持退款，怎么办？"

Agent 会先问你四个问题（谁收的钱、买的什么、用了多少、客服原话），然后给你判断、步骤、话术。

## 边界（重要）

- ✅ 帮你**自己**把钱要回来：判断路径、固定证据、按顺序用渠道、给话术。
- ❌ 不做代退：不替你注册、不冒充你、不碰密码和验证码、不承诺结果、不收费。

"代退"在法律上风险极高，在平台风控里也是重点打击对象——一旦被判定为代退，账号会被封，退款彻底没戏。
